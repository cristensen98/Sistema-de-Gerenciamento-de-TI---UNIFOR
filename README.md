# Sistema de Gerenciamento de TI - UNIFOR

## Descrição

Sistema de Gerenciamento de Tecnologia da Informação desenvolvido para a Universidade de Fortaleza (UNIFOR). O sistema permite gerenciar equipamentos, tickets de suporte, usuários e configurações de rede.

## Recursos Principais

- 📋 **Gerenciamento de Tickets**: Criar, acompanhar e resolver tickets de suporte técnico
- 🖥️ **Gestão de Equipamentos**: Cadastro e controle de equipamentos de TI
- 👥 **Gestão de Usuários**: Gerenciamento de usuários do sistema
- 🌐 **Monitoramento de Rede**: Visualização e gerenciamento de rede
- ⚙️ **Configurações Personalizáveis**: Ajustes de sistema e preferências

## Stack Tecnológico

- **Frontend**: React + TypeScript + Vite
- **Backend**: Node.js + TypeScript
- **Gerenciamento de Processos**: PM2
- **Banco de Dados**: (Conforme configuração)

## Instalação

1. Clone o repositório:
```bash
git clone https://github.com/cristensen98/Sistema-de-Gerenciamento-de-TI---UNIFOR.git
cd Sistema-de-Gerenciamento-de-TI---UNIFOR
```

2. Instale as dependências:
```bash
npm install
```

3. Configure as variáveis de ambiente:
```bash
cp .env.example .env
```

4. Inicie o servidor:
```bash
npm start
```

## Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Compila o projeto
- `npm run preview` - Visualiza a build de produção
